# mantenimiento
Sistema de gestión con React + Node + MySQL
Sistema de Mantenimiento

Sistema web para la gestión y seguimiento de tareas de mantenimiento.

Descripción

Este proyecto consiste en el desarrollo de una aplicación web para gestionar tareas de mantenimiento, permitiendo registrar, consultar y administrar la información relacionada con los trabajos realizados.

El sistema cuenta con un frontend desarrollado en React y un backend desarrollado con Node.js y Express, utilizando MySQL como sistema de gestión de base de datos.

Tecnologías
Frontend: React
Backend: Node.js + Express
Base de datos: MySQL
API: REST
Autenticación: Autenticación y autorización basada en roles
Control de versiones: Git + GitHub

Instalación
Requisitos
Node.js
npm
MySQL
Git
Clonar el repositorio
git clone https://github.com/federicobaez1/mantenimiento.git
cd mantenimiento

Frontend
cd frontend
npm install
npm run dev

Backend
cd backend
npm install
npm run dev

Base de datos

La aplicación utiliza MySQL.
